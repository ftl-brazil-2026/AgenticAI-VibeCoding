# How to contribute

If you are presenting, you can pull-request into the repo. We are very open for improvement in frontend and suggestions to make it more accessible for students. 

## Present a class

Volunteers who would like to present can send their details to the series coordinators:

1. Share a public GitHub repository with the class materials.
2. Write a two-to-three sentence description of what learners will do.
3. Name the roadmap session the class supports, if any.

The coordinators will add a card in the list above and update its status.
