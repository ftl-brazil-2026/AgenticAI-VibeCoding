# Agentic AI Lessons

Let's leave this page to be human written and have some better coordination here.

UNV volunteer series **Agentic Software Development & Vibe Coding**. Here we are gathering the proposed shared roadmap, the lesson index and the class materials that volunteers present, for planning lessons and keep tracking. 

It is an attempt to be a display towards yours own repository that will be used in the classes. The students can always look from here to get to their willing classes and topics. 

The site is built with [Quarto](https://quarto.org) using the `journal` theme. The built site lives in `docs/`, ready to publish with GitHub Pages.


## Modify and contribute for the repo

- Just modify the .qmd or the .md files.

- Feel free to modify the roadmap and correct some themes that are not fitting your class proposal. 

- Add your github in the main page. 

- Please address your class time schedule in the main page as well. 

- pull request into this repo, just quickly comment what you have changed on add. 

- Dont hesitate in contribute, it is a work of many hands. 

## What is in this repository

| Path | Purpose |
|:--|:--|
| `index.qmd` | Home page: roadmap link, class progress table and class entries |
| `README.md` | This page, also published on the site |
| `_quarto.yml` | Site configuration: navbar, theme and output folder |
| `roadmap_cards.html`, `roadmap_cards.js` | Interactive roadmap card view |
| `roadmap_synthesis.md` | Written roadmap and design principles |
| `agentic_vibe_coding_roadmap.js` | Source data for the roadmap (not published) |
| `docs/` | Rendered website, generated by Quarto |

## Build and preview

Install [Quarto](https://quarto.org/docs/get-started/) (version 1.4 or later) and run the commands below from the repository root.

```bash
quarto preview    # live preview while editing
quarto render    # builds the full site into docs/
```

Commit the updated `docs/` folder so GitHub Pages serves the latest version.

## Contributing

Volunteers who present a class should send a public GitHub repository, a short description and the roadmap session it supports. The series coordinators add it to `index.qmd` and rebuild the site.
