Agentic AI & Vibe Coding

UNV volunteer series

This site organises the Agentic Software Development & Vibe Coding series. It gathers the programme material and provides a road map of learning in the quickly evolving field of AgenticAI. The idea is provide an overview and provide some guide of how to develop our own skills to create and assist AgenticAI.

We are also creating the space for community contributions towards open-source and digital soveigrinity. It gives student one place to find the lessons, the shared roadmap and track which classes are ready.

Start here

  • Learning roadmap: interactive card view of all sessions, tracks and comparison of models and costs. cost paths.
  • Roadmap synthesis: the written plan behind the roadmap, with design principles and learner tracks.
  • Standard setup: the tools, folder layout and config rules every volunteer should follow, including WSL on Windows.
  • README: how this repository is organised and how to rebuild the site.
