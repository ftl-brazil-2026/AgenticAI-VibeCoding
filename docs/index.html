Agentic AI & Vibe Coding

UNV volunteer series

This site organises the Agentic Software Development & Vibe Coding series. It gathers the programme material and provides a roadmap of learning in the quickly evolving field of Agentic AI. The idea is to provide an overview and some guidance on how to develop our own skills to create and work with Agentic AI.

We are also creating a space for community contributions towards open-source and digital sovereignty. It gives students one place to find the lessons and the shared roadmap, and to track which classes are ready.

Classes

Class 1: Introduction to the Vibe Paradigm

Presenter: Phyo Ko Ko

Key ideas of Vibe Coding. Setting up a standard dictionary of terms. What is Vibe Coding, and what are the best practices? How are people using Vibe Coding around the world?

Link for the presentation: Presentation

Link for the GitHub: GitHub

Class 2: Architecting and configuring the AI Workspace

Presenter: Ruiya Zhou

How can we properly configure the workspace for working with agents? Which software, tools and libraries are the most used? What do professionals in the field use? These and many more questions will be answered during the session.

Link to Drive: Drive Folder of the Session

Class 3: Development paradigms: Intent-Based “Vibe” Iteration, Spec-Driven, Agentic Orchestration

Presenter: Akshi Rao

What is intent-based? spec-based or agentic orchestration? How does the meaning and the driving intents of your project matters for the outcome of LLMs? What are the human specifications for we need to set up when developing in the agentic AI era?

Link for the presentation: Slides-Presentation

Class 5: Managing Multi-Agent Teams

Presenter: Lwin Ravendom, GitHub Status: Ready Roadmap session: S5

Supervise an agent team through typed handoffs, scoped tools, independent checks and human decisions. The course starts with deterministic fixtures and ends with a Software Factory that builds a minimalist travel website using local files and Git operations. No LLM or API key is needed, so the cost is $0.00.
