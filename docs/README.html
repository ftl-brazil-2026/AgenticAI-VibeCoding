README

Agentic AI Lessons

Course site for the UNV volunteer series Agentic Software Development & Vibe Coding. It gathers the shared roadmap, the lesson index and the class materials that volunteers present, so the team can plan lessons and track progress in one place.

The site is built with Quarto using the journal theme. The built site lives in docs/, ready to publish with GitHub Pages.

What is in this repository

Path Purpose
index.qmd Home page: roadmap link, class progress table and class entries
README.md This page, also published on the site
_quarto.yml Site configuration: navbar, theme and output folder
roadmap_cards.html, roadmap_cards.js Interactive roadmap card view
roadmap_synthesis.md Written roadmap and design principles
agentic_vibe_coding_roadmap.js Source data for the roadmap (not published)
docs/ Rendered website, generated by Quarto

Add a class from a volunteer

  1. Open index.qmd.
  2. Add a row to the Class progress table with the class number, topic, presenter and status.
  3. Copy one of the Class sections and fill in the topic, presenter, GitHub link and description. Replace the placeholder text.
  4. Set the status to Planned, Ready or Delivered.

Use the number of the next free slot. To add more slots, copy an existing section and increase the number.

Build and preview

Install Quarto (version 1.4 or later) and run the commands below from the repository root.

quarto preview    # live preview while editing
quarto render    # builds the full site into docs/

Commit the updated docs/ folder so GitHub Pages serves the latest version.

Contributing

Volunteers who present a class should send a public GitHub repository, a short description and the roadmap session it supports. The series coordinators add it to index.qmd and rebuild the site.
